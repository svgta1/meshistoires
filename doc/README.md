# Gestion des données

Le site "Mes Histoires" n'utilise pas de cookie.

Le site "Mes Histoires" enregistre des données dans votre navigateur internet afin d'améliorer les performances d'accès.

Le site "Mes Histoires" ne collecte aucune donnée.

## Données transmises à un tiers

&#x20;Le site "Mes Histoires" **ne transmet aucune information quelle qu'elle soit à un tiers**.
